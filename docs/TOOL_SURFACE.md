# Tool surface policy

Keep tools **few, powerful, and obvious**.

1. Prefer one primary read/index tool agents reach for first.
2. Add secondary tools only when they change modality (crop, render, path, cache).
3. Do not explode schema with vanity micro-tools.
4. Tool Search / deferred discovery is fine; still avoid confusing near-duplicates.
5. Advanced tools may exist but must be labeled advanced in docs.
