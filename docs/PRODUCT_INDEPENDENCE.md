# Product independence

This repository is the **only source of truth** for this product:

- marketplace listing
- release train
- package / CLI / MCP / SDK contracts
- docs, tests, and stars

There is **no** central Instruments monorepo and **no** shared product-control package authority.

Sibling agent tools (if useful) are **separate public repositories**. Composition is via public SDK/MCP contracts only — never source import of another product, and never an archived family package as SSOT.

Company-level private portfolio map (internal): `SylphxAI/portfolio` (thin map only; not product SSOT).
