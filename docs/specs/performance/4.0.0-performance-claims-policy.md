# Sole-Rust 4.0.0 performance claims policy

Status: **withhold marketing speedup claims**  
Date: 2026-07-24

## Decision

The sole-Rust 4.0.0 candidate may ship **without** public marketing speedup claims.

Same-host A/B drafts exist (`measured_draft_not_admissible`) and are useful diagnostics only.

## Why not admissible yet

1. Fixture set is still a small local corpus (not full small/medium/large/scanned/table-heavy/hostile production scorecard).
2. Peak RSS / startup / package-size methodology is incomplete or host-dependent.
3. Independent review has not authorized performance claims.
4. Historical cross-run numbers remain forbidden.

## Allowed public statements for 4.0.0 (if released under freeze lift later)

- Sole-Rust production path (no TypeScript PDF runtime in package)
- Capability-first semantic compatibility (ADR-0005)
- Five-host runtime proof for the exact candidate
- Optional: “local same-host diagnostic measurements exist; not published as marketing guarantees”

## Forbidden

- “Nx faster than TypeScript” in README/release notes without `status=admissible_pass` + independent authorization
- Cherry-picked single-fixture speedups as product claims

## Path to admissible claims (post-4.0.0 or before if completed)

1. Expand fixture classes and iterations.
2. Record cold/warm, median/p95, RSS, startup, package/install size with bound SHA/binaries/toolchains.
3. Independent review sets `performanceClaimsAuthorized=true`.
4. Publish honest report derived from raw samples.
