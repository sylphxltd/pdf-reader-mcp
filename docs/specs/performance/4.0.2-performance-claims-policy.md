# Sole-Rust 4.0.2 performance claims policy

Status: **bounded same-host claims authorized**  
Date: 2026-07-24  
Independent review: `verification/pdf-reader-whole-product-independent-review-4.0.2-perf-16fc2eb.json`

## Decision

Public performance claims for `@sylphx/pdf-reader-mcp@4.0.2` are authorized **only**
within the honest bounds below. Unbounded marketing speed guarantees remain
forbidden.

## Preconditions satisfied

1. `verification/pdf-reader-same-host-ab-suite-4.0.2.json` → `status=admissible_pass`
2. Independent review set `performanceClaimsAuthorized=true`
3. Honest report derived from raw suite samples:
   - `docs/specs/performance/4.0.2-same-host-performance-report.md`
   - `verification/pdf-reader-same-host-ab-report-4.0.2.json`

## Allowed public statements (must keep the bounds)

- On a controlled same-host linux-x64 A/B of initialize + `read_pdf` page 1 with
  `include_full_text` against immutable `@sylphx/pdf-reader-mcp@3.0.14`, sole-Rust
  4.0.2 achieved at least ~**6.2x** lower warm median latency across all eight
  required fixture classes (min class speedup ~6.25x; median of class speedups
  ~23.7x).
- The published sole-Rust launcher package tarball is substantially smaller than
  the historical TS 3.0.14 tarball; the platform native binary remains
  multi-megabyte via optionalDependencies.
- Sole-Rust production with empty production dependencies and no shipped
  TypeScript PDF runtime/PDF.js.

## Forbidden without successor review

- “Nx faster” as a universal / multi-host / all-PDF-topology guarantee
- Peak RSS / memory superiority claims (suite RSS was null on the runner)
- OCR / scanned external-provider path latency claims
- Cherry-picked single-fixture speedups presented as the product-wide minimum
- Historical cross-run numbers as guarantees
