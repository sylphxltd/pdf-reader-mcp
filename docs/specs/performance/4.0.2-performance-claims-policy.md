# Sole-Rust 4.0.2 performance claims policy

Status: **withhold marketing speedup claims until suite admissible_pass + independent authorization**  
Date: 2026-07-24

## Decision

4.0.2 may ship (and is live) as a sole-Rust dependency-closure product without
public marketing speedup guarantees.

## Path to claims

1. `bun run perf:same-host-ab-suite` → `status=admissible_pass`
2. Independent review sets `performanceClaimsAuthorized=true`
3. Publish honest report from raw suite samples

## Forbidden

- Claiming Nx faster from single-fixture or historical cross-run numbers
- Goal-complete claims based only on packaging cutover
